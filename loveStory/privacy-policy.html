二、我们收集哪些个人信息及使用目的

我们遵循最小必要原则收集信息。收集的信息范围、目的及场景如下：

信息类别具体字段使用目的触发场景
账号信息 账号标识、昵称、头像等您主动提供的信息 识别用户身份、完成登录、保存游戏进度 您使用账号登录游戏或完善资料时
设备信息 设备型号、操作系统版本、屏幕分辨率、系统语言与时区、设备标识符（如 Android ID、OAID） 机型适配、版本兼容、数据统计与故障排查 游戏启动及运行期间
网络信息 IP 地址、网络类型（Wi-Fi / 移动网络）、运营商信息 保障服务稳定、进行安全风控与异常识别 游戏连接网络服务时
日志与崩溃信息 运行日志、崩溃堆栈、错误代码 定位并修复问题、提升游戏稳定性 游戏发生异常或崩溃时
广告交互信息 广告标识符、广告曝光与点击记录 广告投放与效果统计 如本游戏接入广告服务，您浏览或点击广告时
用户主动提供的信息 反馈内容、客服沟通记录 处理您的问题、建议与投诉 您主动提交反馈或联系我们时

我们不会收集与本政策所述目的无关的个人信息。如需将信息用于新的用途，我们会另行告知并视情况征得您的同意。

设备权限说明：为实现上述功能，本游戏可能在运行时向您申请存储、设备信息等系统权限。我们仅在您授权后调用相关权限，且仅用于机型适配、数据统计与故障排查等本政策所述目的；您可以随时在设备的系统设置中关闭相关权限。关闭后可能影响部分功能，但不会影响本游戏其他功能的正常使用。

三、信息的存储与保护

  • 存储地点：中华人民共和国境内。
  • 保存期限：为实现本政策所述目的所必需的期限内保存；法律法规另有规定的，从其规定。期限届满后，我们将对相关信息进行删除或匿名化处理。
  • 安全措施：我们采用传输加密（HTTPS）、访问权限控制、数据最小化收集、定期安全评估等合理措施保护您的个人信息，防止数据泄露、篡改或丢失。
  • 互联网环境并非绝对安全，我们将持续努力提升安全防护水平。若不幸发生个人信息泄露等安全事件，我们将按照法律法规要求及时告知您并采取补救措施。

四、信息共享与第三方 SDK

除下列情形外，我们不会向任何第三方提供您的个人信息：

  1. 第三方 SDK 的使用

    截至本政策更新日期，本游戏暂未接入第三方 SDK，不会因使用第三方 SDK 而向第三方提供您的个人信息。本游戏的登录、实名认证与防沉迷等服务由 TapTap 平台统一提供，不属于本游戏接入的第三方 SDK。为维持游戏运营及后续功能升级，我们可能在未来接入广告等第三方 SDK；届时我们将提前更新本政策，并通过游戏内公告等方式向您提示。接入后，相关 SDK 收集的信息及用途预计如下：

    SDK 类型可能收集的信息使用目的
    广告 SDK 广告标识符、广告曝光与点击记录、设备信息 广告投放与效果统计

    上表为前瞻性说明，仅在本游戏实际接入相应 SDK 后适用。第三方 SDK 将按其自身隐私政策处理相关数据，您可以前往其官方网站查看。

  2. 法定情形：根据法律法规规定，或应司法机关、行政机关等有权机关的合法要求而提供。
  3. 业务变更：如发生合并、收购、资产转让等情形，我们会在转移前告知您，并要求继受方继续履行本政策项下的义务。

五、您的权利

您依法对自己的个人信息享有以下权利。您可以通过本政策第八节提供的联系方式向我们提出申请，我们将在核实您的身份后 15 个工作日内予以响应：

  • 查询与更正：查询我们是否持有您的个人信息，并对不准确的信息进行更正。
  • 删除：在特定情形下请求删除您的个人信息。
  • 撤回授权：您可以在设备系统设置中关闭相关权限（如存储、设备等权限）。撤回授权不影响撤回前基于该授权已进行的信息处理活动。
  • 注销账号：您可以通过本政策第八节所列邮箱与我们联系，申请注销账号。
  • 其他权利：在适用法律允许的范围内，您还可以请求获取个人信息副本、限制信息处理等。

六、未成年人保护

  • 年龄限制：本游戏仅面向 16 周岁及以上的用户，年龄限制为 16+。未满 16 周岁的用户请勿使用本游戏。
  • 我们高度重视未成年人保护。若您为已满 16 周岁但未满 18 周岁的未成年人，请在监护人陪同下阅读本政策，并在取得监护人同意后使用本游戏。
  • 本游戏的实名认证与防沉迷功能依托 TapTap 平台统一提供的服务实现，相关规则由平台执行，未成年人用户将受到游戏时长、游戏时段及充值等方面的限制。我们自身不单独收集未成年人用户的身份信息。
  • 若我们发现在未事先取得监护人同意的情况下收集了未成年人的个人信息，将尽快予以删除。监护人如发现相关情况，可通过本政策所列邮箱与我们联系。

七、本政策的更新

  • 因法律法规变化、业务调整或技术升级等原因，我们可能适时修订本政策。修订后的条款自公布之日起生效。
  • 本政策发生变更时，我们会同步更新本页顶部标注的「更新日期」（当前为 2026年11月24日），并通过游戏内公告等方式向您提示；涉及重大变更的，我们将以显著方式通知，并在必要时重新征得您的同意。
